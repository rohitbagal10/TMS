* Instructions to run the project.

-I have used node - v18.16.1
- Install Dependencies
    npm install
- Start the Development Server
    npm start
This will start the React application automatically at - http://localhost:3000


* Overview of implemented features.

1. User Authentication:

Implemented user authentication using Firebase Authentication with Google Sign-In.

2. Task Management:

Users can create, edit, and delete tasks.
Implemented task categorization (e.g., work, personal) and tagging for better organization.
Users can set due dates for tasks.
Implemented drag-and-drop functionality to rearrange tasks within the boards.
Users can sort tasks based on due dates (ascending/descending).

3. Batch Actions:

Users can perform batch actions on tasks (e.g., delete multiple tasks, mark multiple tasks as complete).

4. Task History and Activity Log:

Implemented a feature that tracks changes made to tasks (e.g., creation, edits, deletions) and displays an activity log for each task.\

5. File Attachments:

Users can attach files or documents to tasks for additional context.
Implemented a file upload feature in the task creation/editing form and display the attached files in the task detail view.

6. Filter Options:

Implemented filtering by tags, category, and date range.
Users can search tasks by task title.

7. Board/List View:

Users can switch between a board view (Kanban-style) and a list view for their tasks.

8. Responsive Design:

Application is fully responsive, adapting to various screen sizes (mobile, desktop) with a mobile-first design approach.

 
* Technical Requirements

1. Used React with JavaScript.
2. Used Firebase for user authentication and data storage.
3. Utilize React-Redux library for data fetching and state management.
